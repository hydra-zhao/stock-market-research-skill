# tactics/ — 战术层（公开演示版）

生产仓库的本目录含短线波段战术层（`a-stock-swing.md`，62KB 完整战术手册）
与规则回测台（`backtest.py`）。**战术内容与回测实现属于私有策略，不在本
仓库公开。**

保留的工程概念：

- 战术文档同样遵循"动作必须引用规则 ID + canonical 字段"的写法约束；
- `backtest.py` 的定位：回测/统计是**事实层**，不直接产生交易规则——
  解读回四人裁决（规则库中的 `OUT-907` 类纪律）。规则反事实回测台
  （`data/backtest_rules.py`，生产版）据此设计。
