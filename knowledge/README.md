# knowledge/ — 进化与红线（公开演示版）

生产仓库的本目录含：

- `EVOLUTION_RULES.md`：规则进化准入标准（什么证据可以升格/降权一条规则）
- `red-lines.md`：不可逾越的红线清单（风控底线）
- `test-cases/`：规则进化用历史案例

**内容属于私有策略积累，不在本仓库公开。** 工程概念：规则不是拍脑袋改的
——每次升格/降权必须有证据链（复盘中落盘的事实 artifact），且受
`AGENTS.md` 的"自我进化准入标准由 Sol 裁决"约束；配套的自动进化控制器
（`data/selection_evolution.py`，生产版）把"样本不足不动阈值"纪律代码化。
