# 示例交易心法文档（虚构示例 · 格式演示）

> 本文件演示生产版 systems/*.md 的结构契约。所有内容为虚构，不构成
> 任何交易方法论。

## 1. 体系定位

- **轨道**：趋势波段（3-20 交易日）
- **在四人裁决中的角色**：示例——情绪/生态裁决（引用规则 `ECO-901`）
- **与其他体系的关系**：被更高优先级的风控体系否决时，本体系结论失效

## 2. 市场观（示例骨架）

- 周期阶段划分：启动 → 扩散 → 高潮 → 退潮 → 出清（示例五阶段）
- 每阶段给出：**可观察特征**（引用 canonical 事实层字段，如
  `market.limit_up` / `market.max_ladder`）+ **阶段任务**（进攻/防守/观望）
- ⚠️ 生产版在此给出具体数值特征与判定规则（私有）；示例版只展示
  "特征必须锚定 canonical 字段"的写法约束

## 3. 仓位纪律（示例骨架）

- 阶段 → 风险敞口上限的映射表（示例版留空，生产版为私有参数）
- 单票/总仓位/回撤线的约束以规则 ID 引用（如 `RISK-901`），
  **心法不得与规则库冲突**（规则库优先）

## 4. 操作手册（示例骨架）

| 场景 | 触发条件（引用字段） | 动作 | 引用规则 |
|---|---|---|---|
| 示例场景 A | `eco.state == "main_rise"` 且梯队高度抬升 | 观察/预案 | POOL-902 |
| 示例场景 B | 断板大面计数上升 | 收缩敞口 | RISK-901 |

## 5. 与管道的对接

- 本文档只被 Agent 在对应场景深读；判定阈值的生产实现在决策层
  （`data/strategy/`，公开版为 mock）；
- 文档中出现的所有字段名必须存在于 canonical context schema
  （`data/schemas/quick_context.schema.json`）。
